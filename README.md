# 🛍️ Shopper Spectrum

A Customer Segmentation & Product Recommendation Dashboard built using **Python, Streamlit, SQL, Machine Learning, and Data Visualization**.

## 🚀 Live Demo

👉 https://shopper-spectrum-bksbm7m658zipwjzgvwcew.streamlit.app/

## 📌 Features

- 📊 Interactive Dashboard
- 👥 Customer Segmentation using Machine Learning
- 🎯 Product Recommendation System
- 🗄️ SQL Analytics
- 📈 Business Insights & Visualizations
- ⚡ Real-time Prediction

## 🛠️ Tech Stack

- Python
- Streamlit
- SQL (MySQL)
- Pandas
- NumPy
- Scikit-learn
- Plotly
- Matplotlib
- Seaborn
- Joblib
