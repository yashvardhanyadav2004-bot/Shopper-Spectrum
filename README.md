# 🛒 Shopper Spectrum

## AI-Powered Customer Analytics & Product Recommendation System

Shopper Spectrum is an interactive business analytics dashboard developed using **Python, Streamlit, SQL, and Machine Learning**. It helps businesses analyze customer purchasing behavior, perform RFM-based customer segmentation, generate business insights, and recommend similar products using an AI recommendation engine.

---

## 🚀 Features

- 👥 Customer Segmentation using K-Means Clustering
- 📊 RFM (Recency, Frequency, Monetary) Analysis
- 📈 Interactive Business Dashboard
- 🗄 SQL Analytics Dashboard
- 🎯 AI Product Recommendation System
- 🌍 Country-wise Dashboard Filters
- 📊 Interactive Plotly Charts
- 💡 Business Insights & Recommendations

---


```bash

```
